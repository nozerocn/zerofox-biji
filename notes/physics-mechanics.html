力学

运动学基本公式（匀变速）

  • 速度：v = v₀ + at
  • 位移：x = v₀t + ½at²
  • 速度-位移：v² − v₀² = 2ax
  • 平均速度：v̄ = (v₀ + v)/2（仅匀变速）

受力分析四步

  1. 先画重力；
  2. 再画已知外力（拉力、推力）；
  3. 绕接触面找弹力（垂直接触面）；
  4. 沿接触面找摩擦力（与相对运动/趋势方向相反）。

多力时建系做正交分解：沿运动方向和垂直方向列方程。

牛顿运动定律

  • F 合 = ma：先整体求加速度，再隔离求内力（连接体问题）。
  • 超重/失重看竖直方向加速度：向上 a 超重，向下 a 失重，a=g 完全失重。

功能关系

规律条件 / 表达式
动能定理W 合 = ΔEₖ（无条件，最常用）
机械能守恒只有重力/弹力做功：Eₖ₁+Eₚ₁ = Eₖ₂+Eₚ₂
功能原理W 除重力外 = Δ机械能

常见模型

  • 斜面：mgsinθ 沿面向下；f = μmg·cosθ（滑动）。
  • 传送带：分“共速前/共速后”两段讨论，注意摩擦力方向突变。
  • 板块：隔离两物分别列牛顿定律，位移关系找摩擦生热 Q = f·Δx相对。
力学大题通用流程：定对象 → 画受力 → 列方程（牛顿/动能/守恒）→ 代数求解。先选“能量观点”往往比纯力观点快。
