高频虚词速查

虚词主要用法例
之代词 / 结构助词“的” / 取消句子独立性 / 动词“到”辍耕之垄上
其代词 / 语气副词（表推测、反问、期望）其皆出于此乎
而并列 / 承接 / 转折 / 修饰学而不思则罔（转折）
以介词“凭、用、因” / 连词“来、因为” / 动词“认为”以光先帝遗德
于介词“在、到、对、被、比”受制于人（被）
乃于是、才 / 竟然 / 是乃不知有汉（竟然）

特殊句式四大类

  • 判断句：…者，…也；乃/则/即表判断。
  • 被动句：于、见…于、为…所、被。
  • 倒装句：宾语前置（何陋之有）、状语后置（青取之于蓝）、定语后置（马之千里者）。
  • 省略句：省主语、省“于”——翻译时必须补全。

翻译六字诀

  1. 留：专名、年号、官名照抄。
  2. 删：无实义的音节助词删去。
  3. 补：补出省略的成分。
  4. 换：古今异义词换成现代说法。
  5. 调：倒装语序调回正常。
  6. 贯：修辞、典故意译贯通。
得分点意识：翻译题按“关键字词 + 特殊句式 + 语句通顺”给分。逐字落实再连缀成句，不漏得分点。
