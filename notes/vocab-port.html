词汇笔记 · port 词族

核心词根 port = 拿、运、搬运（也指“港口”，船运货物之地）。记住它，下面一片词都能顺藤摸瓜：

单词结构含义
port—港口；（v.）搬运
importim- (in) + port进口，输入
exportex- (out) + port出口，输出
transporttrans- (across) + port运输，运送
portableport + -able便携的（可搬运的）
reporterre- (back) + port + -er记者（带回消息的人）
passportpass- (通过) + port护照（通过港口的凭证）
portfolioport + folio(页)作品集；公文包
supportsub- (under) + port支持（在下面托住）

记忆小窍门

  • 方向前缀：im- 进、ex- 出、trans- 横穿、re- 回、sub- 下——换前缀换方向，词根不变。
  • 人 / 物后缀：-er 表人（reporter），-able 表“可…的”（portable）。
  • 造句巩固：The reporter carried a portable laptop to the port to report on exports.
一组词根 = 一串单词。比起孤立背拼写，理解结构记得更牢、用得更活。
