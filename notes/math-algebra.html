函数与数列

函数三要素与性质

  • 定义域优先：求值域、解方程前先写定义域（分母、根号、对数真数）。
  • 单调性：定义法（取值→作差→变形→定号）或导数法。
  • 奇偶性：先看定义域是否关于原点对称，再验 f(-x) 与 f(x) 的关系。

三角函数常用结论

结论内容
诱导公式口诀奇变偶不变，符号看象限
辅助角公式a·sin x + b·cos x = √(a²+b²)·sin(x+φ)
正弦定理a/sinA = b/sinB = c/sinC = 2R

数列

  • 等差：aₙ = a₁ + (n−1)d，前 n 项和 Sₙ = n(a₁+aₙ)/2。
  • 等比：aₙ = a₁·qⁿ⁻¹（注意 q=1 时求和退化为 na₁）。
  • 求和方法：裂项相消、错位相减、分组求和——看结构选方法。
  • 递推式常用思路：构造 aₙ₊₁ + λ = q(aₙ + λ) 化为等比。

导数应用

  1. 切线：y − f(x₀) = f′(x₀)(x − x₀)（注意“在点处”与“过点”的区别）。
  2. 单调性：f′(x) > 0 递增；极值点两侧变号才算极值。
  3. 恒成立/能成立：分离参数后转为最值问题（恒成立 ≤ 最大，能成立 ≥ 最小）。
大题套路相对固定：先写定义域，再求导列表，最后答单调区间与极值——步骤分一分不丢。
